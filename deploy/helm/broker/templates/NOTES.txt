IMPORTANT CAVEATS
------------------
1. Distributed/clustered mode in brokerd itself is EXPERIMENTAL and, per the
   project's own Tasks.md, NOT PRODUCTION-SAFE.{{ if .Values.cluster.enabled }}
   This release has clustered mode enabled for {{ .Values.replicaCount }} pods;
   this is not a certified production cluster. Raft membership changes must
   use the broker's membership workflow; do not scale this StatefulSet by
   changing replicaCount alone.{{ else }}
   With cluster.enabled=false, replicaCount {{ .Values.replicaCount }} runs
   independent standalone brokers, each with its own WAL volume and identity.{{ end }}
2. The native BST1 TCP stream (port 8091) is disabled by default
   (broker.listeners.native.enabled=false). It supports token or mapped mTLS
   authentication. Enabling it adds the port to both Services. When
   `networkPolicy.enabled=true`, ingress remains denied until
   `networkPolicy.nativeIngressFrom` lists authorized peers. Configure
   production TLS/authentication and restrict external access if
   `service.type` is NodePort or LoadBalancer.
3. If you installed with default values and did not override `secrets.*` /
   `tls.*`, the admin token, AMQP credentials, and TLS certificate are
   PLACEHOLDERS. Replace them before accepting real traffic; the default TLS
   certificate will not pass a real TLS handshake.

NEXT STEPS
----------
1. Replace placeholder secrets before using this anywhere but a scratch
   cluster:

     helm upgrade {{ .Release.Name }} deploy/helm/broker -n {{ include "broker.namespace" . }} \
       --set-string secrets.adminToken="$(openssl rand -hex 32)" \
       --set-file tls.crt=/path/to/server.crt \
       --set-file tls.key=/path/to/server.key

   or set `secrets.existingSecret` / `tls.existingSecret` to a Secret you
   manage with sealed-secrets / external-secrets / SOPS. Clustered mode
   requires `tls.existingSecret` to contain `tls.crt`, `tls.key`, and `ca.crt`;
   the certificate must cover every pod DNS name under the headless service.

2. Check rollout status:

     kubectl -n {{ include "broker.namespace" . }} rollout status statefulset/{{ include "broker.fullname" . }}

3. Verify health once pods are Ready:

     kubectl -n {{ include "broker.namespace" . }} exec {{ include "broker.fullname" . }}-0 -- \
       wget -qO- --no-check-certificate https://127.0.0.1:8090/healthz

4. Port-forward for local testing:

     kubectl -n {{ include "broker.namespace" . }} port-forward svc/{{ include "broker.fullname" . }} 8090:8090

5. Read docs/OPERATIONS.md in the broker repository for backup/restore and
   rolling-upgrade procedures before operating this in anything that
   matters.
